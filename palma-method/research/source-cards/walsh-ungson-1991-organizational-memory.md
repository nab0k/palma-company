# Organizational Memory (Walsh and Ungson, 1991)

## Priority given to primary text / official data

Citation and DOI confirmed directly via the publisher's own journals page
(journals.aom.org/doi/10.5465/amr.1991.4278992). The five-bin model and the
paper's own definition of organizational memory are corroborated identically
across five independent secondary sources, including a peer-reviewed
citation-context study (Anderson & Sun, 2010, published in *Organization
Studies* family journals) built specifically around what later scholarship
retrieved from this paper. Full primary-text retrieval (page-level
quotation) was not attempted in this pass - this card is at the same
"checked, not verified" tier as several sources in
`PALMA_TRANSITION_MODEL_PRIOR_ART_CLOSURE_v0.1.md`, not the stronger
"verified via primary source" tier used for sources like SC-110.

## Specific fragments supporting the claim

The five retention bins (individuals, culture, transformations, structures,
ecology) and the paper's own definition of organizational memory as "stored
information from an organization's history that can be brought to bear on
present decisions" - see YAML fields above.

## Why this source deserves a place in the project

`INFRASTRUCTURE_CANVAS_INTERNAL_AUDIT_v0.1.md` (TASK_CLAUDE_0028, Stream 1)
found that "Memory" is the one Infrastructure Canvas field with no
predecessor source card anywhere in this project's corpus, no counterpart in
Chapter 13's six design elements, and the widest period-mixing problem in
the only full worked example that exists (the TAK.Shtab retrospective
Canvas fill). Stream 2 of the same task treated this as a genuine gap
worth closing with a properly bounded, honestly labeled card, rather than
stretching an unrelated existing card (Ostrom, Selznick, or Wenger) to
cover a construct none of them actually studied.

## What is original in it

Not original to this project - a verification record of an established,
widely-cited 1991 organizational-behavior framework, newly connected to the
Palma Infrastructure Canvas by this project.

## Limitations / competing interpretation

Citation-and-abstract-level verification only, not primary-text-verified.
Built for large/formal organizations; applying it to small or newly-forming
groups (TCF, TAK.Shtab in its first weeks, Bombom) is this project's own
extension, consistent with the model's own scope but not a direct 1991
finding about those contexts.

## Permissible level of claim

"Walsh and Ungson (1991) propose that organizational memory is distributed
across five distinct retention bins, and that memory concentrated in only
the individual bin is a different, more fragile condition than memory
distributed across more than one bin" - supportable, at the citation-checked
tier. "This project's Infrastructure Canvas Memory field has been validated
against Walsh and Ungson's model" - NOT supportable and not claimed here;
no Canvas fill in this project has yet been re-analyzed using the five-bin
test.

## Forbidden overgeneralization

Do not use this card to imply the Infrastructure Canvas's Memory field has
been empirically tested or that the five-bin model has itself been verified
against any of this project's own cases - it has only been identified as a
relevant, properly cited theoretical anchor.
