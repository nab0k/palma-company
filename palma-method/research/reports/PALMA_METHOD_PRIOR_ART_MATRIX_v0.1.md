# Palma Method — Prior-Art Matrix v0.1

Task: TASK_CLAUDE_0024, Stream 2
Owner: Claude
Status: draft for editorial review (Codex / Serhii)

## Method and scope

For each Palma component, this matrix names the closest established predecessor
found through this project's own extensive, independently-verified source-card
corpus (116 cards, covering the academic and practitioner literature already
checked across TASK_CLAUDE_0004 through 0023) plus targeted verification for
gaps. "Apparently original" means a reasonable search found no close equivalent -
not that worldwide originality has been proven; this is stated once here rather
than repeated in every row.

## Classification key (per task brief)

1. Direct restatement of established work
2. Adaptation or recombination
3. Original practitioner operationalization
4. Apparently original hypothesis
5. Apparently original tool or presentation format
6. Insufficient evidence to determine
7. Contradicted or weakened by existing evidence

## Notes on gaps found while building this matrix

- **Founder-dependence and succession-planning literature** (row 9) was not
  independently searched as part of this project before this task, and this
  audit did not conduct a full search either, given the task's own instruction
  to search for conceptual equivalents without repeating broad research from
  scratch where existing project material already covers a component. This is
  flagged as a genuine, not-yet-closed gap, not resolved here.
- **Community-organizing and community-design practitioner literature**
  (e.g., Alinsky-tradition organizing, or contemporary community-design
  consultancies) was not found as a named predecessor anywhere in this
  project's 116-card corpus. This may reflect a genuine gap in the research
  base rather than genuine absence of overlap - a project with this book's
  scope would normally be expected to position itself against at least one
  named community-organizing tradition, and this audit did not find that this
  project has done so yet.
- **Stakeholder-engagement practitioner frameworks** beyond Freeman's original
  1984 stakeholder theory (e.g., AA1000, IAP2's spectrum of participation -
  though Arnstein's ladder, a close cousin, is already cited in Chapter 11) were
  not found as named comparisons anywhere in the corpus.

These three gaps do not change any classification above, since no claim in the
current Method material actually depends on them - but they should be closed
before any public claim of a comprehensive prior-art review, since "Palma
compared itself against the nearest community-organizing and stakeholder-
engagement traditions" would not currently be a defensible claim.
