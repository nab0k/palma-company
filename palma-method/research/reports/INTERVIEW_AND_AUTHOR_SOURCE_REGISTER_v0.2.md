# Interview and author-source register v0.2

## Purpose and authority

This is the stable navigation layer for private interviews and Serhii's author
stories. It supersedes v0.1 for discovery but does not alter or replace any
source card. GitHub stores public-safe editorial knowledge; raw recordings,
private transcripts, sensitive personal detail, and contact data remain in
approved private locations.

Registration is not manuscript approval. The source card's
`personal_story_use`, verification limits, naming decision, and quotation
permissions govern every use.

The private reconstruction key is recorded in TASK_CODEX_0020. It is an
operational locator, not a second canonical version store. This public register
does not repeat the private page URL; an agent must already have authorized
access to the private workspace before following that route.

## Rules for the next AI

1. Search this register and linked cards before searching chats or asking Serhii
   to repeat a story.
2. If a story exists only in SC-092, treat it as a discovery lead, not a
   publication source.
3. Do not copy private audio or raw transcripts into this public repository.
4. Do not turn an author's remembered sequence into a causal conclusion.
5. Do not interpret registration as consent. Check `personal_story_use` and the
   card's naming/quotation gate.
6. Before opening a new author interview, check the collection queue so the
   interview closes an actual chapter or evidence gap.
7. When placement changes, update this register in a new append-only version;
   do not silently rewrite historical cards merely to match the latest outline.
