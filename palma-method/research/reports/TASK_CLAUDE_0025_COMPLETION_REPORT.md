   checked against the full sequence, not just single components already
   catalogued in TASK_CLAUDE_0024 — Wenger/McDermott/Snyder's (2002)

   stage model, and the community-organizing practice tradition's mobilization-
   to-turnover sequence. Each is a genuine nearest-neighbor for part of the
   chain; none matches the whole. No equivalent integrated model was found —

   originality.

   requester named (Feld, Collins, Wenger, social/relational capital,
   collective efficacy, network formation/interventions, community organizing,
   institutionalization/succession) — the one precise surviving novelty claim
   identified: the specific causal linkage between a dyadic mechanism (a
   consequential, participant-initiated action) and a system-level outcome
   (infrastructure operationally defined by organizer-independence), which no
   single checked literature makes explicit.
3. **Formal model specification** — constructs, boundaries between them, unit
   of analysis (dyad and system, explicitly not collapsed), causal sequence,
   necessary vs. facilitating conditions, boundary conditions, three
   alternative explanations (selection effect, age/size confound, reverse
   causation), six observable indicators, two counterexamples drawn from
   already-documented material, and two new integration-level falsifiable
   propositions (P6, P7) beyond the five the requester specified.
4. **P1-P5 individually tested** against established/synthesis/new,
   falsifying evidence, TCF illustrate/explore/test status, and additional
   data needed. None reaches "test" status against current material; P5 is
   closest to already-illustrated (Bombom's own case already shows the
   pattern it describes).
5. **Scientific contribution package** — all four positions weighed explicitly,
   including the reasoning for rejecting the two adjacent ones (practitioner-
   novelty-only was the closest competitor, rejected specifically because P6/
   P7 are genuinely researcher-relevant, not just consultant-relevant;
   preliminary-empirical-contribution was rejected clearly, since no actual
   data analysis has been performed against any proposition). **Selected:
   defensible conceptual novelty with untested propositions.** Exact draft
   language provided for the book, an academic abstract, and an Amazon
   description, each explicitly separating established research from Palma's
   synthesis from this book's new proposal from what remains untested.
6. **Minimal preregistration protocol** for a future coding pass against the
